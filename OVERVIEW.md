Pi Subagents shows background Pi jobs in Paseo's sidebar and Explorer. Browse running and recent jobs, inspect child models, tokens, tools and output, send guidance, and request a graceful stop.

The sidebar shows jobs across the selected host. The Explorer panel starts with the current workspace and can switch to all jobs. On narrow screens the roster and child details appear one at a time with a Back button. Pi sessions also get a Pi Subagents composer button, which provides a direct mobile entry point even when the plugin sidebar is hidden. Status refreshes every three seconds and output every two seconds while the view is open. Each run and child now shows best-effort progress: exact workflow/chain position where available, checklist-based estimated percentage from a safe `progress.md`, or an indeterminate phase when no denominator is available. Estimates show their evidence source, confidence, and update time; token count is not treated as progress.

Requires Paseo 0.12.0 or later and pi-subagents using the standard temporary run directory on the same daemon machine. Existing background runs appear automatically. Completed jobs remain visible while pi-subagents retains their artifacts. Foreground-only jobs and remote machine artifacts are outside this panel's scope.

The daemon reads local pi-subagents status and bounded output artifacts. It writes guidance and stop requests into the runner's portable control inbox only when you press the corresponding control. Guidance is initially queued; the panel shows the runner's delivered, pending and failed counts. A stop requires a second tap. Workflow roots expose child links because each detached child owns its own controls. Restarted and resumed runs are linked through their recorded `revivedFrom`, `resumeOrigin`, `workflow-revival.json`, and follow-up metadata. The detail view shows the original attempt, every known restart, missing retained artifacts, the parent workflow, and the current attempt. Stale status from an exited runner is labeled unavailable.
